# Power-Supply-Analytics
Power supply diagnostics and analytics platform for live monitoring, spectral analysis, fault characterization, and AI-ready data generation.

Power Supply Analytics is a modular engineering platform for monitoring, analyzing, and characterizing precision power supply systems. It combines live telemetry, fault diagnostics, FFT/PSD analysis, stability measurements, magnet-load characterization, and external oscilloscope data processing within a common framework. The platform is also designed to generate correlated, AI-ready datasets for future predictive fault detection and anomaly analysis.
